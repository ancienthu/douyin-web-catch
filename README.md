# 抖音 / TikTok 作品清单

在已登录的抖音或 TikTok 作者主页，把公开视频整理成可搜索的列表，支持单条视频下载和 Excel 导出。

**当前版本：0.2.1 · Chrome 本地安装 · 无需服务器或填写 Cookie**

本项目为独立开发的第三方工具，与抖音、TikTok 官方无关联。

## 下载安装

[下载本地安装包](https://github.com/ancienthu/douyin-web-catch/raw/refs/heads/main/dist/douyin-worklist-0.2.1.zip)，解压后保留 `douyin-worklist` 文件夹。

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 **douyin-worklist 文件夹**，其中应直接包含 `manifest.json`。
4. 打开抖音或 TikTok 网站、手动登录并进入作者主页，刷新页面。
5. 「作品清单」按钮只在个人主页显示，离开个人主页后自动隐藏。点击页面右侧「作品清单」，或点击浏览器工具栏中的插件图标。

如果下载的是 GitHub 仓库源码，第三步选择仓库里的 **extension 文件夹**。安装后请保留该文件夹，Chrome 会从这里读取插件文件；ZIP 不能直接拖入安装。

更新时用新文件替换原安装目录，在扩展管理页点击本插件的重新加载按钮，再刷新作者页面。刷新会清空当前采集结果，需要的列表请先导出。

## 功能

- **读取作品**：点击「读取全部」，自动逐页读取并去重；列表按每页 50 条显示。
- **搜索与排序**：在全部已读取数据中搜索名称、简介或作品 ID，按发布时间、点赞、分享、评论排序。
- **单条下载**：每行独立下载，不提供批量下载。先检查视频地址，再交给 Chrome 下载；默认保存在下载目录的 `抖音作品` 或 `TikTok作品` 子目录。
- **Excel 导出**：导出当前搜索和排序后的全部结果，不限于当前显示页；包含作品数据和采集说明两个工作表。
- **数据管理**：关闭侧栏保留数据且不会打断读取；刷新、离开、关闭页面或切换作者时清理，也可手动「清理数据」。

主动读取受限时，可以打开一次侧栏后滚动作者主页，收集页面正常加载的作品。「停止」会同时停止主动读取和滚动收集。

## TikTok 支持说明

- 支持 `www.tiktok.com/@用户名` 作者主页；推荐页、搜索页、单条视频页和直播页隐藏入口。
- 使用当前网页的登录状态和请求包装器读取 `/api/post/item_list/`，自动分页、按作品 ID 去重；页面尚未加载请求参数时，向下滚动主页后再点击「读取全部」。
- 站内切换作者后，会从当前作者主页重新核对资料，并恢复该作者近期请求中的必要参数，无需先手动刷新页面。主页响应限制为 5 MiB，仅解析初始 JSON，不执行返回的页面脚本。
- 只复用当前作者的一份有上限的请求参数，不复制或生成签名、不读取 Cookie，不将参数写入磁盘；手动清理、页面离开或切换作者后释放。
- 返回空响应、验证页或异常分页时保留现有结果并提示未完成；打开侧栏后也可滚动收集网页正常加载的作品。
- 已在登录后的真实作者主页验证完整读取、跨页搜索、Excel 导出和单条 MP4 下载；一次实测读取 100 条视频、跳过 15 条图文，与主页的 115 个作品对应。
- TikTok 下载预检使用浏览器已有的登录会话，无需复制 Cookie。视频链接仍可能受地区、网络和平台访问限制影响；返回 403 的地址会在创建下载任务前被拦截。

## 导出字段

名称、简介、点赞量、分享量、评论量、作品 ID、作者、发布时间、作品链接、采集时间、名称来源。

- 名称优先使用作品标题，否则从文案截取；简介为作品文案。
- 分享量对应抖音接口的 `share_count`、TikTok 接口的 `shareCount`，不保证等同于独立的「转发量」。
- 缺失统计不当作 0；不展示或导出播放量。
- 采集时间按电脑本地时区显示为 `YYYY-MM-DD HH:mm:ss`。
- 长作品 ID 和文案以文本保存，避免数字舍入和公式误执行。

## 数据与权限

作品列表只在当前页面内存中处理，不上传至开发者服务器，不持久化全量作品；不读取或导出 Cookie。

| 权限 / 网站 | 用途 |
| --- | --- |
| `www.douyin.com`、`www.tiktok.com` 页面脚本 | 读取当前作者资料和作品列表，展示侧栏 |
| `downloads` | 发起单条视频下载并显示结果 |
| `storage` | 在浏览器会话中暂存下载任务状态 |
| `*.douyinvod.com`、`*.douyincdn.com`、`*.tiktok.com`、`*.tiktokcdn.com`、`*.tiktokcdn-us.com` | 下载前检查视频 CDN 响应，不跟随重定向；TikTok 检查使用浏览器已有登录会话，抖音检查不携带 Cookie |

只缓存文案、统计和下载地址，不缓存视频或图片文件。缓存上限为 10,000 条视频或约 32 MiB 序列化数据；达到上限会停止读取并提示结果不完整。该预算不是浏览器进程内存上限，页面和 Excel 导出仍有额外开销。已保存到电脑的文件不会被清理。

## 使用范围与常见问题

- **读取结果少于主页作品数**：图文会跳过，账号可见范围和接口统计口径也可能不同。只有接口明确返回最后一页才标记读取结束；中断或滚动收集的结果会标记为部分数据。
- **下载失败**：视频链接可能失效，重新读取作品后再试。预检与正式下载之间，服务器响应仍可能变化；不保证所有作品均可下载。
- **安装后没有侧栏**：确认打开的是 `https://www.douyin.com/user/...` 或 `https://www.tiktok.com/@用户名` 作者主页，并在安装或更新后刷新页面。
- **接口发生变化**：抖音和 TikTok 网页接口不是稳定的公开 API，平台调整可能导致功能失效。

请仅下载你拥有权利或已获得授权的作品，并遵守平台使用规则。本项目不提供无水印承诺、评论内容抓取或云端服务。

## 开发

使用 Node.js 22 或更新版本，无需安装 npm 依赖；打包需要 Python 3。

```sh
npm test
npm run check
npm run package
```

- `extension/`：可直接加载的扩展源码和图标。
- `dist/`：最新版本地安装包。
- `scripts/`：检查和打包脚本。
- `tests/`：采集、分页、缓存、下载及 Excel 的自动化测试。
